Technologies Behind the Design

 

VLSM

Variable-length subnet masking allocates each subnet from the largest to the smallest requirement, so address space is never wasted.

VLANs + 802.1Q Trunks

Department traffic is isolated into VLANs and carried between switches and routers on tagged trunks. VLAN 99 is the native and unused-port VLAN.

Router-on-a-Stick

One physical router port with a sub-interface per VLAN performs all inter-VLAN routing.

OSPF

Single-area link-state routing re-converges automatically when a link fails. Manual router IDs keep the database easy to read.

HSRP

Two routers share one virtual gateway per VLAN. If the active router fails, the standby takes over and hosts never change their gateway.

EtherChannel (PAgP)

Two physical links are bundled into one logical trunk for more bandwidth and automatic failover.

DHCP + Relay

One central server hands out addresses for both branches; relay agents forward broadcast requests across the WAN.

AAA with RADIUS

Logins are checked centrally for auditing, with a local admin account as a safety net.

SSH v2

Encrypted remote management replaces Telnet on every internal router.

Static NAT

A one-to-one translation publishes the internal web server on the public address 50.50.50.2.

Password Hardening

Enable secret, line passwords and service password-encryption protect every device.

Documentation

Every step is recorded in a PDF report with screenshots and plain-language explanations.
