The Project

Brief, requirements and verification results

The Brief

 
Task: You are a network engineer. Choose any organization, then plan, design and implement its network - using variable subnetting.

We chose a multi-site enterprise with a Headquarters (HQ) and a Regional Branch (RB). Departments such as Sales & Marketing, HR, Finance & Accounting and IT sit at HQ, while Customer Support, Operations / Logistics, Research & Development and Legal & Administration sit in the Regional Branch. A central Edge router connects both sites to a DMZ web server and to the ISP.

Requirements and How We Met Them

 
#RequirementOur implementation
1VLSMEvery segment uses the smallest prefix that fits its hosts: /25, /26, /27, /28 and /29 for LAN VLANs, /30 for point-to-point WAN links. No overlaps.
2OSPF routingProcess 1, area 0 on the five internal routers with manual router IDs (1.1.1.1 - 5.5.5.5). passive-interface default keeps hellos off the LANs. The Edge router advertises the default route.
3VLANs + Router-on-a-StickEach branch switch pair carries its VLANs over an 802.1Q trunk (native VLAN 99). Each router uses one sub-interface per VLAN on Gig0/0.
4Standalone DHCP serverServer0 (10.10.1.36) holds eight scopes for both branches. ip helper-address on every user sub-interface relays requests across the WAN.
5AAA + local adminServer2 (10.10.1.37) runs RADIUS. Routers use aaa authentication login ... group radius local, so the local admin account still works if the server is down.
6Line passwords = first nameConsole, Aux and VTY lines are protected, and service password-encryption hides them in the configuration.
7Enable password = second namePrivileged EXEC mode is protected with an enable secret (MD5 hashed).
8Web server with public IP 50.50.50.2Server1 sits in a DMZ behind the Edge router. Static NAT (ip nat inside source static 10.40.0.2 50.50.50.2) publishes it to the ISP side.
9EtherChannel for backupTwo links between each switch pair are bundled into Port-channel 1 using PAgP and trunked, giving double bandwidth and automatic failover.
10HSRP redundancyActive/Standby router pairs share a virtual IP per VLAN. The active router has priority 110 with preempt; the standby has priority 100.
11SSH on the routersSSH version 2 with a 1024-bit RSA key on all five internal routers; VTY lines accept SSH only.

Requirement 11 of the brief - documentation - is delivered as a detailed PDF report with screenshots and short explanations for every step.
