About This Project

 

This website presents the CCNA Capstone Project built by our team at the Information Technology Institute (ITI), Ismailia branch. The brief was simple to state and demanding to deliver: act as a network engineer, choose an organization, then plan, design and implement its complete network - using variable-length subnet masking (VLSM) throughout.

We designed an enterprise with a Headquarters, a Regional Branch and a central Edge router that reaches the Internet through a simulated ISP. Every segment is sized to its real host count, every gateway has a standby, every management session is authenticated, and an internal web server is published to the outside world on the public address 50.50.50.2.

Project Highlights

 

Smart Addressing

VLSM sizes each subnet to the smallest prefix that fits its department, with /30 links on the WAN and no overlap across 9 VLANs.

Dynamic Routing

Single-area OSPF (area 0) links HQ, Regional Branch and Edge, and the Edge router originates the default route to the ISP.

High Availability

HSRP gives every VLAN a shared virtual gateway, while a PAgP EtherChannel doubles inter-switch bandwidth and survives a link failure.

Centralised Services

One standalone DHCP server serves both branches through DHCP relay, and a RADIUS server handles router logins with a local fallback account.

Secure Management

Passwords are encrypted, the enable mode is protected, and VTY access is SSH version 2 only - Telnet is disabled.

Public Web Publishing

Static NAT maps the internal web server to 50.50.50.2 so an external client can browse it through the ISP.

Where Are We?

 

We are students of the Cloud Architecture track at the Information Technology Institute - Ismailia (Suez Canal Branch). The CCNA capstone is where the networking foundation of the track comes together: switching, routing, redundancy, security and services in a single working design.
